# Routes Configuration

TanStack Router file-based routing configuration for the Code Inventory Dashboard.

## Route Structure

```
src/routes/
├── __root.tsx           # Root route with ErrorBoundary
└── dashboard/
    └── index.tsx        # Dashboard route (/dashboard/)
```

## Route Details

### Root Route (`__root.tsx`)

The root route wraps all routes with an ErrorBoundary to catch rendering errors.

**Path**: All routes
**Features**:
- Global error boundary
- Outlet for child routes
- Can be extended with global providers

### Dashboard Route (`dashboard/index.tsx`)

Main dashboard visualization route.

**Path**: `/dashboard/`
**Features**:
- Lazy loading with React.lazy
- Suspense boundary with SuspenseLoader
- Breadcrumb: 'Dashboard'
- Data fetching via useDashboardData hook

## Component Hierarchy

```
RouterProvider
  └─ ErrorBoundary (from __root.tsx)
      └─ Suspense (from dashboard/index.tsx)
          └─ Dashboard (lazy loaded)
              └─ DashboardLayout
                  ├─ Header
                  ├─ Sidebar
                  └─ Content
                      ├─ HealthSummary
                      └─ MetricGrid
```

## Loading States

### Code Loading (Lazy Import)

When the dashboard route is first accessed, the Dashboard component is lazy loaded:

```tsx
const Dashboard = lazy(() => import('@/features/dashboard/components/Dashboard'));
```

During this time, the SuspenseLoader is displayed.

### Data Loading (Suspense Query)

The Dashboard component uses useSuspenseQuery which suspends rendering until data loads:

```tsx
const { data } = useDashboardData(outputsPath);
```

The SuspenseLoader continues to display during data fetching.

## Error Handling

Errors are caught at two levels:

1. **Root ErrorBoundary**: Catches all routing and rendering errors
2. **Dashboard Errors**: Data fetching errors throw to the ErrorBoundary

The ErrorBoundary displays:
- User-friendly error message
- Retry button
- Detailed error info (development only)
- Helpful troubleshooting tips

## Route Generation

The route tree is auto-generated by TanStack Router CLI:

```bash
# Generate route tree once
npm run routes:generate

# Watch for changes and auto-generate
npm run routes:watch
```

This creates `src/routeTree.gen.ts` from your route files.

## Adding New Routes

### 1. Create Route File

Create a new file in `src/routes/`:

```tsx
// src/routes/reports/index.tsx
import { createFileRoute } from '@tanstack/react-router';

export const Route = createFileRoute('/reports/')({
  component: ReportsPage,
  loader: () => ({ crumb: 'Reports' }),
});
```

### 2. Generate Route Tree

```bash
npm run routes:generate
```

### 3. Access Route

Navigate to `/reports/` - the route will be automatically available.

## Route Configuration

Configure routing behavior in `tsr.config.json`:

```json
{
  "routesDirectory": "./src/routes",
  "generatedRouteTree": "./src/routeTree.gen.ts",
  "routeFileIgnorePrefix": "_",
  "quoteStyle": "single"
}
```

## Type Safety

TanStack Router provides full TypeScript type safety:

```tsx
import { Link } from '@tanstack/react-router';

// ✓ Type-safe - route exists
<Link to="/dashboard/">Dashboard</Link>

// ✗ Type error - route doesn't exist
<Link to="/invalid/">Invalid</Link>
```

2. **Data Caching**: React Query caches dashboard data
3. **Suspense**: Smooth loading transitions
4. **Error Boundaries**: Graceful error recovery

## Troubleshooting

### Route Not Found

- Ensure route file follows naming convention
- Run `npm run routes:generate` to regenerate route tree
- Check file is in `src/routes/` directory

### Suspense Loader Not Showing

- Verify Suspense wrapper in route component
- Check that Dashboard uses useSuspenseQuery
- Ensure SuspenseLoader is imported correctly

### Error Boundary Not Catching Errors

- Verify ErrorBoundary in __root.tsx
- Check error is thrown (not caught internally)
- Use React DevTools to inspect component tree

### Type Errors

- Regenerate route tree: `npm run routes:generate`
- Check TypeScript version compatibility
- Verify route paths in type declarations
